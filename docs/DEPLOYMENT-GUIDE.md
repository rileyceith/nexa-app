**No additional configuration needed** unless changing domains.

### Step 3: Database Migration

Automatic at startup:
```bash
# In Render's startCommand:
python manage.py migrate --noinput      # Applies 0017
python manage.py createcachetable        # Cache setup
gunicorn nexa.wsgi --bind 0.0.0.0:$PORT # Start server
```

**What 0017 Does**:
- Adds `team_sharing_enabled` boolean to UserSettings
- Creates `TeamMembership` table (owner, member, permissions, timestamps)
- Creates `TeamInvitation` table (email, token_hash, expiration, accepted_at)
- Adds indexes on (owner, member) and (owner, email) for performance

**Safety**: Additive only; no existing tables modified; rollback by reverting to migration 0016.

## Rollback Procedure

### Quick Rollback (< 5 minutes)
If critical issue occurs immediately after deployment:

1. **Render Dashboard**
   - Select the previous deploy version
   - Click "Rollback to this version"
   - Service restarts with previous code

2. **Automatic Rollback** (no code change needed)
   - Database changes are additive; migration 0017 tables just go unused
   - Team features inaccessible but no data loss
   - Existing business data unaffected

### Full Rollback (if needed)

```bash
# 1. Rollback code to previous commit
git revert ee49f83  # Create a revert commit

# 2. Optionally rollback database
# (Only if data corruption suspected; unlikely with additive migration)
python manage.py migrate api 0016  # Revert schema to previous migration

# 3. Push and redeploy
git push origin main
```

**Note**: Team feature will be disabled; no data loss.

## Feature Flags & Configuration

### Team Sharing Feature Control

**Flag**: `UserSettings.team_sharing_enabled` (opt-in at registration)

**To enable for existing user**:
```python
from api.models import UserSettings
user_settings = UserSettings.objects.get(owner=user)
user_settings.team_sharing_enabled = True
user_settings.save()
```

**To globally disable** (not recommended):
```python
# Disable feature for all users (but don't delete data):
from api.models import UserSettings
UserSettings.objects.all().update(team_sharing_enabled=False)
```

## Troubleshooting Guide

### "Invitation link not working"

**Problem**: User clicks email link, page shows 404 or blank.

**Solutions**:
1. Check `NEXA_FRONTEND_URL` matches email link domain
2. Verify invitation hasn't expired (7 days)
3. Check browser console for JS errors
4. Test with different browser/device

### "403 Forbidden when accessing business data"

**Problem**: Member can't access permitted scope.

**Solutions**:
1. Check workspace selection: Does workspace switcher show team workspace?
2. Check permission grant: Is scope in Team Settings with correct permission?
3. Check permission normalization: Can't have edit without view
4. Clear browser cache; try incognito window

### "Team member doesn't appear in member list"

**Problem**: Owner invites member, but member doesn't show until page refresh.

**Solutions**:
1. Expected behavior: Frontend caches team member list (reload required)
2. Check member email: Must match invitation email exactly
3. Check member status: If not accepted yet, appears in "Pending Invitations"

### "HTTPS redirect loop"

**Problem**: URL keeps redirecting (infinite loop).

**Solutions**:
1. Likely Render misconfiguration: Ensure app doesn't redirect HTTPS → HTTPS
2. Check `SECURE_SSL_REDIRECT` in development (should be False only)
3. Contact Render support if issue persists

### "Session cookies not secure in production"

**Problem**: Browser console shows "Sensitive Cookie 'sessionid' should have been sent with 'Secure' flag."

**Solutions**:
1. Expected: Warn if accessed over HTTP (should be HTTPS only)
2. Verify HTTPS redirect works: `curl -i http://api.Nexa-app.com/`
3. All production traffic should be HTTPS; redirect catches any HTTP
